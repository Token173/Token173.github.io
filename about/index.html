关于本站

这里记录大模型 API 中转、聚合与接入过程中的实际问题：怎么选、怎么配、怎么算账、出了问题怎么查。

内容来自公开资料与真实接入记录，尽量给出可复现的命令、字段名、报错码和记录表，而不是结论式的推荐。

内容范围

选型与验收方法、国内直连与协议配置、按家族整理的模型型号清单、计费口径与账单对账、风险边界，以及多模型调度和长耗时任务的工程实践。

更新口径

模型 ID、分组和价格变动频繁，文中不写死具体折扣或可用性数字。接入前请以平台控制台和价格页当前公示为准，并用 /v1/models 核对一次可用型号。

风险提示

第三方 API 中转是预充值服务，请求会经过第三方服务器，存在上游波动、账号风控、数据留存与资金敞口风险。敏感数据不要走公共托管链路，额度按周小额充值，主力之外留一条备用通道。

本站不代任何平台作资质背书，也不承诺稳定性或折扣数字。
