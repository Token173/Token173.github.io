关于本站

一份关于大模型 API 中转、聚合与接入的技术笔记。

写什么

选型与验收、国内直连与协议配置、模型型号清单、计费口径与对账、风险边界、多模型调度工程实践。内容按公开资料和实际接入过程整理，带可复现的命令、字段名、报错码和记录表。

不写什么

不列无来源的排行榜，不承诺任何平台的稳定性或折扣数字，不代任何平台作资质背书。所有型号 ID、价格与规则都会调整，文中一律以平台控制台当前公示为准。

风险提示

第三方 API 中转属于预充值、请求经过第三方服务器的服务形态，存在上游波动、账号风控、数据留存与资金敞口风险。请自行评估，敏感数据不要走公共托管链路，额度按周小额充值。
