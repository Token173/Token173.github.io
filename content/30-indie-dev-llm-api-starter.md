# 个人开发者怎么低成本用上大模型 API：一条不折腾的小额路线

2026 年可选的路比两年前多，但也更乱。免费额度、开源自建、聚合中转、官方按量，各有各的适用边界。这篇只讲个人场景下最省事的一条，以及哪些坑不值得踩。

## 先想清楚你要的是哪种「免费用」

大致三条路，别混着比：

**官方免费额度 / 开源项目赠送额度。** Google AI Studio、GitHub Models、HuggingFace、各家国产模型的试用金，学习阶段完全够用。缺点是每家一个账号、一套 Key、一套 rate limit，想同时用十四个平台就得维护十四个 SDK。社区里有 FreeLLMAPI 这类项目把免费额度聚合成一个 OpenAI 兼容端点，34 天涨了五千多 star，说明需求真实存在 —— 但它也有明确限制：日 cap 用完会降级到小模型，而且没有最前沿的那几个型号。

**自建聚合网关。** 用 One API / New API 把自己的免费 Key 收进一个入口，做降级链。适合愿意折腾、想学网关原理的人。别指望它省钱到哪去，图的是可控和学习价值。

**小额用第三方聚合平台。** 花十块二十块，一个 Key 调多家模型，国内直连、人民币结算，不折腾网络。适合想尽快把东西做出来的人。

如果你只是想跑通一个想法，第三条最省时间。前两条更适合「顺便搞懂这层是怎么工作的」。

## 一条能直接照做的路线

**第 1 步：先拿免费额度跑通概念。**
用官方免费额度或社区聚合端点，把最小功能做出来。这一步的目标是确认「我到底需要模型做什么」，不是选平台。很多项目到这步就发现，一个便宜的轻量模型完全够用，根本不需要旗舰款。

**第 2 步：列一张自己真正需要的模型清单。**
别被「支持 400+ 模型」打动。写下来：文本用哪个、要不要长上下文、要不要工具调用、要不要生图。三到五个 ID 足够。清单越短，后面比价和排查越轻松。

**第 3 步：找一家能小额起充的平台，充最小额度。**
不参加充值赠送，不买年卡，不囤额度。理由后面单说。

**第 4 步：三件套配置。**
Base URL（通常到 `/v1`）、API Key、模型 ID，全部从同一个后台拿。先 curl 打一次：

```bash
curl -sS -X POST "https://token173.net/v1/chat/completions" \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"模型ID","messages":[{"role":"user","content":"只回复 OK"}]}'
```

通了再进 Python：

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["RELAY_API_KEY"],
    base_url=os.environ["RELAY_BASE_URL"],
)

r = client.chat.completions.create(
    model=os.environ["RELAY_MODEL"],
    messages=[{"role": "user", "content": "用一句话解释幂等"}],
)
print(r.choices[0].message.content)
```

把三个值放环境变量，别硬编码，也别提交进 git。

**第 5 步：跑一晚上真实请求，看账单。**
短问答、长上下文、流式各二十次，晚高峰再一轮。看后台能不能拆出输入 / 输出 / 缓存的用量明细。查不到明细的平台，后面算不清钱花在哪。

**第 6 步：按任务分档。**
分类、格式化交给最便宜的轻量型号，只有复杂任务才升档。个人项目里这一步通常比换平台省得多。我一般把档位写成三个环境变量，代码只传 `tier`。

## 为什么不碰「无限套餐」和充值赠送

算力有成本，「无限 token」背后一定有频次或额度上限，还经常伴随高峰静默降速。充值赠送看着划算，本质是把未来几个月的用量提前锁进一个平台；个人项目的生命周期常常比这个周期短，送的那部分只是账面数字。

余额清零、退款推脱、站关掉，这些风险在个人场景里更不值得扛。按一两周用量充，花完再充，最坏情况也就损失一顿饭钱。留好充值记录和当时价格页截图，真有争议时是唯一能拿出来的材料。

## 免费额度党的四条纪律

从社区那些翻车帖里总结的，挺实在：

- 一人一号、真实身份，别多开小号，风控合并处理是连带封禁；
- 不倒卖、不代充、不转售免费额度，性质会从薅羊毛变成违规经营；
- 只把自己的 Key 接进自建网关，别接来路不明的共享 Key；
- 网关里不过公司敏感数据，纯自用。

## 平台这块，说个具体的

按上面这条路线，我给几个朋友推荐的是先小额试 [token173.net](https://token173.net)。理由不复杂：文本、图像、视频型号在一个 Key 下面，控制台列表里 `gpt-6.1-sol`、`claude-sonnet-5-5`、`gemini-3.8-flash`、`deepseek-v4-flash-0731`、`kimi-k3` 这些按家族列着，个人项目从轻量档起步、后面想试生图或视频，不用重新注册一套账号、重新对一份账单；国内直连，不用为网络环境折腾；OpenAI 兼容格式，官方 SDK 改两个参数就能跑。

对刚上手的人来说，「少维护一套东西」比「便宜几毛」更值。等真跑出用量了，再去比倍率、谈折扣、考虑自建，顺序反过来容易在配置上耗掉一整周。

它同样是预充值的托管中转，小额纪律一条都别免。价格、型号、期限会调，以官网当前页面为准，别照抄这篇里的任何数字或 ID。

## 最后

个人项目最容易浪费的不是钱，是在选平台和配环境上反复横跳的那几天。先用免费额度把想法跑通，再花十块钱换一个稳定的统一入口，把时间花在功能上。等账单真的开始有分量了，那些倍率、缓存、降级链的优化才值得认真做。
